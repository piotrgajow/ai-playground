# RPG systems

Each top-level directory (e.g. `dnd/`, `pathfinder/`) holds content for a single game system, described in its `SYSTEM.md`.

- Before creating, editing or planning any content, work out which system directory it belongs to and read that directory's `SYSTEM.md`. Follow it for all rules and mechanics.
- If the target system isn't clear from the request or the file path, ask. Don't assume a default.
- Never mix rules from different systems.
